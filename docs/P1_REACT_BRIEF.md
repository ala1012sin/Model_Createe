# Claude 구현 지시서 — P1 React 데이터셋 첫 화면

> `CLAUDE.md`, `ARCHITECTURE.md`, `REQUIREMENTS.md`, `SCREEN_DESIGN.md`의 S1·S1-T, `CONTRACTS.md`, `PROGRESS.md`를 읽고 **React + TypeScript 첫 화면과 FastAPI 연동**을 구현해 줘. 기존 `DatasetService`를 호출해 합성 CSV 업로드부터 실제 로컬 프로파일 확인과 실패 후 재시도까지 브라우저에서 검증해 줘. 이번 작업의 대상은 DATA-01과 DATA-02의 CSV 경로야.

## 첫 화면

- 앱을 열면 한글 **데이터셋** 화면이 먼저 나온다. 맨 왼쪽에는 화면 공통 세로 메뉴를 둔다. 위에서부터 데이터셋, 전처리, 학습 설정, 실행·결과, 새 데이터 적용을 배치하고 설정은 하단에 둔다. 아이콘과 한글 이름, 현재 항목 표시를 쓰고 후속 화면은 연결 예정 상태로 보여준다. 같은 탐색 항목을 상단에 반복 배치할 필요가 없다.
- 세로 메뉴 오른쪽 본문의 약 30%는 파일 선택·드래그앤드롭, 등록 목록과 처리 상태에 사용한다. 나머지 약 70%에는 선택한 파일의 이름, 행·열 수, 피처명·추정 타입·결측률·고유값과 시간열 후보·간격을 둔다. 좁은 창에서는 세로 메뉴를 아이콘 중심으로 줄이고 접근 가능한 이름을 유지한다. 본문에서는 업로드·목록 아래에 구조 패널을 둔다.
- 행·열 수와 시간열을 한눈에 찾을 수 있게 배치하고, 동일한 글자 크기 체계와 여백을 사용한다. 목록의 선택 상태와 진행·완료·실패는 색과 한글 텍스트로 구분한다. 좁은 창에서도 표의 각 열을 확인할 수 있어야 한다. 파일 선택, 목록 이동, 재시도는 키보드로도 동작한다.
- 빈 상태, 업로드 중, 분석 중, 완료, 실패를 각각 처리한다. 브라우저가 전송량을 알 때만 업로드 비율을 표시한다. 분석 중에는 서버 상태와 경과 시간을 보여준다. 실패 행에서 한글 원인을 확인하고 수정한 파일을 선택해 같은 데이터셋 ID로 다시 등록할 수 있다.
- 시간열·타깃·선택적 설비 구분 열·예측 구간 입력은 구조 패널 아래에 둔다. 실제 목표 확정은 기존 초안 서비스에서 검증·저장하고, 재조회할 수 있게 한다. 설비 구분 열은 사용자가 직접 고른다. 전처리 화면이 연결되기 전에는 목표 저장까지만 브라우저에서 검증한다.

## 연결과 범위

- 저장소의 `frontend/`에 React + TypeScript, `src/mlworkbench/api/`에 FastAPI를 둔다. 업로드·목록·상태·선택 데이터셋의 로컬 프로파일·재시도를 연결한다. 로컬 웹 기본 주소를 사용하고, 도메인 처리는 기존 Python 서비스에 둔다. `doctor`의 P1 웹 의존성 안내는 FastAPI에 맞춘다.
- 분석이 끝날 때까지 브라우저에서 다른 데이터셋을 선택하고 상태를 조회할 수 있게 한다. 등록·파일 해시 계산·CSV 파싱처럼 오래 걸릴 수 있는 동기 작업은 API 이벤트 루프를 막지 않는 경로에서 실행한다. 파일은 기존 크기 제한과 스트림 복사를 사용하고, 화면용 응답에는 요약만 보낸다. 서버의 절대경로, 파일 내용, 예외 원문을 응답에 넣지 않는다. CSV의 파일명과 헤더는 화면에서 일반 텍스트로 렌더링한다.
- 이미지/XLSX 등록, S2 추천, 외부 LLM, 학습은 후속 작업이다. 화면의 파일 선택은 이번에 연결한 CSV 형식에 맞춘다. 20만 행은 기존 벤치마크 입력 크기다. 제품 제한으로 도입할 경우 용량·메모리 근거와 별도 결정이 필요하다.

## 완료 확인

- 실제 합성 CSV 두 개를 올리고 왼쪽 목록을 바꿔 선택할 때 오른쪽 행 수와 피처가 정확히 바뀌는지 확인한다. 새로고침 후 등록 결과를 다시 읽고, 잘못된 CSV → 한글 오류 → 수정 파일 재등록까지 확인한다.
- 실제 브라우저의 넓은 창과 좁은 창에서 왼쪽 세로 메뉴의 선택 상태, 연결 예정 안내, 본문의 가독성과 키보드 조작을 확인한다. 큰 합성 CSV 분석 중에도 목록과 상태를 계속 볼 수 있는지 확인한다. 검증 데이터의 행 수와 방법을 기록한다.
- Python 회귀 테스트, FastAPI 연결 테스트와 프런트엔드 빌드를 실행한다. README에 로컬 실행법을, PROGRESS.md에 실제 테스트와 브라우저 검증 결과를 남긴다.
