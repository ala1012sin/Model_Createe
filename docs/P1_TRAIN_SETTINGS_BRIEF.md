# Claude 구현 지시서 — P1 S3 시계열 학습 설정

> `CLAUDE.md`, `SCREEN_DESIGN.md` §7, `REQUIREMENTS.md`, `CONTRACTS.md` §11, `PROGRESS.md`를 읽고 **S3 학습 설정의 시계열 초안 편집·검증·저장**을 구현해 줘. S1 목표와 S2 전처리를 보존하면서 같은 초안 리비전에 모델·학습량·분할·평가를 반영해 줘.

공유 폴더에 반영하기 직전에 수정 대상 파일을 다시 확인한다. 시작 이후 다른 변경이 들어온 파일은 현재 내용에 필요한 변경을 병합하고 그 파일의 회귀 테스트를 다시 실행한다.

## 화면과 저장

- S2에서 초안을 저장하고 학습 설정으로 이동할 수 있게 한다. 세로 메뉴와 새로고침에서 같은 데이터셋을 유지한다. 설정은 기존 상단 바와 사이드 메뉴 아래에 **모델 / 학습 데이터량 / 분할·평가** 세 섹션으로 배치한다.
- **모델:** 등록된 시계열 예측 후보와 정확한 버전, 추천 여부, 파라미터 및 구현 상태를 표시한다. XGBoost가 미구현이면 저장 가능한 계획 미리보기로 명시한다. 카탈로그의 `ready`와 승인·실행 차단 규칙을 유지한다.
- **학습량:** `전체` 또는 `학습 구간의 최근 N일`을 선택한다. 학습량을 바꿔도 검증·테스트 구간에는 영향이 없음을 같은 그림에서 보여준다. 분할 그림의 기본은 설정 비율을 보여주는 개념도다. 실제 사용 기간·행 수는 파이프라인이 계산한 경우에만 표시한다.
- **분할·평가:** 시간순 학습·검증·테스트 비율, 예측 구간에 따른 자동 경계 간격, MAE·RMSE와 기준 예측 설정을 제공한다. 기본값은 70/15/15, MAE·RMSE, 직전값 기준 예측이다. 예측 구간별 집계와 설비 구분 열이 있는 경우의 설비별 집계 설정을 기존 계약에 연결한다. 지원하는 설정을 정확히 표시하고, 비율 합·범위, 최근 일수, 최소 지표 수 등 오류를 해당 입력 근처에 보여준다.
- 기존 `PlanService`와 FastAPI를 사용한다. 부분 수정 시 S1 목표·S2 선택과 제외 항목·추천 이력을 보존한다. 같은 초안의 예상 리비전으로 업데이트하고, 충돌하면 최신 상태를 다시 읽을 수 있게 안내한다. 최종 승인이나 작업 제출은 여기서 발생하지 않는다.

## 상단 검색의 이동 규칙

데이터셋 화면에서는 입력과 함께 목록을 필터링한다. 전처리나 학습 설정 화면에서는 입력하는 동안 현재 화면을 유지하고, Enter로 검색을 확정하면 데이터셋으로 이동한다. 저장하지 않은 편집이 있다면 저장하거나 변경을 버릴지 선택할 수 있게 한다. 상단 바의 창 드래그와 Windows 창 버튼 동작에 대한 기존 검증을 유지한다.

## 완료 확인

- 실제 브라우저에서 S1 목표 저장 → S2 전처리 저장 → S3 진입 → 최근 30일·다른 분할 비율·평가 지표를 설정해 저장 → 새로고침 후 복원을 확인한다. 저장 전후 S1/S2 설정이 보존되고, 잘못된 비율이나 파라미터는 오류를 보여주는지 확인한다.
- 초안 미저장 상태에서 상단 검색을 입력만 하는 경우와 Enter로 다른 화면으로 이동하는 경우를 모두 확인한다. 합성 데이터로 API·기존 회귀 테스트, 프런트엔드 빌드, 브라우저 검증을 실행해 `PROGRESS.md`에 기록한다.
- 이번 작업은 P1의 설정 편집까지다. S4 승인, 실제 기간·샘플 계산과 학습 실행, 비전 설정, 개인 프리셋 저장은 각각 로드맵의 후속 범위에서 진행한다.
